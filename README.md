# Debugging Assessment – Section A

This repository contains explanations, corrected C++ programs, and expected console outputs for the five debugging problems supplied in Section A.

## Contents
1. `Question_1_Dangling_Reference.md` – Returning references and object lifetime
2. `Question_2_Static_Member.md` – Static member definition and static-function scope
3. `Question_3_Overload_Ambiguity.md` – Overload resolution and default arguments
4. `Question_4_Default_Constructor.md` – Arrays of objects and constructors
5. `Question_5_Friend_Function.md` – Forward declarations and friend-function access

## Notes
- The explanations follow the supplied problem statements.
- Console outputs are expected outputs based on the corrected code; they should be checked by compiling and running the programs in the submission environment.
- Each question is kept in a separate Markdown file for easy review.
